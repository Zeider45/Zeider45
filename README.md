## Sobre mí

Construyo aplicaciones web completas: interfaz, API, base de datos y despliegue. Programo desde 2021 y últimamente mi trabajo se ha movido hacia sistemas de gestión y software financiero: una intranet corporativa, una plataforma de créditos y fondos, y una red bancaria de práctica con core, switch interbancario y home banking.

También automatizo tareas con Python (conversión masiva de archivos, OCR, monitoreo de logs) y me gusta que lo que entrego quede documentado y se pueda levantar con Docker.

**Disponible para proyectos freelance y posiciones remotas.** Detalle de servicios en [yender-rodriguez.online](https://yender-rodriguez.online/#services).
